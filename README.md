Preparei os três materiais com enfoque de design instrucional para formação profissional no setor têxtil:

Storyboard completo — roteiro detalhado do curso Introdução à Indústria 4.0 no Setor Têxtil, com objetivos, competências, etapas, cenas, narração, interações e avaliação.

Objeto de Aprendizagem – Articulate Rise — estrutura de 5 telas para o minicurso Segurança no Trabalho em Confecções, incluindo objetivos, conteúdo, interações e feedback.

Infográfico educativo — Ciclo de produção de um tecido sintético, contemplando matéria-prima, polimerização, fiação, preparação, formação do tecido, beneficiamento, inspeção e produto final.

Os materiais foram estruturados para poderem ser posteriormente transformados em objetos educacionais interativos, situações de aprendizagem e materiais didáticos com padrão SENAI.
